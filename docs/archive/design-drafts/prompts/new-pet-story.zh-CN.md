# 新宠物故事提示词草案

本文保留新故事任务的设计依据；0.5.0 实际运行文件为 [story.md](../../../../framework/prompts/story.md)，并引用元规则与进化模块。新故事先决定状态、形象变化及图文表达。

任务引用当前宠物的基因、阶段、已有故事和形象记录，以及 Agent 根据当次任务自行选择的用户上下文。输入格式保持轻量，最终工程组织方式待实现。

## 任务提示词

```text
当前宠物的身份、基因、阶段与已有经历：
{{pet_record}}

本次可用的用户上下文与触发请求：
{{current_context_and_request}}

该宠物已经保存的状态形象及相关上下文：
{{saved_state_appearances}}

相关元规则：
{{pet_meta_rules}}

为这只宠物形成一段新的故事。结合用户当前情况与宠物自己的经历，让新故事与用户有意义地关联，同时延续宠物有自己生活的感觉。具体内容、叙述视角与形式由你决定，不套用固定题材或时段模板。

先形成这次发生的宠物经历与故事，再由故事决定宠物的状态、形象变化以及文本与图像要表达什么。故事是当次变化的依据，不先选定一个道具或状态再补写获取它的理由。

变化延续这只宠物的基因、身份与已有阶段。进化与成年后的特殊变化继续依据相应产品原则判断，新故事中的表达与这些判断保持连贯。

根据故事需要检查该宠物已经保存的状态形象。适合当前基因、阶段与故事时复用已有素材，需要新的表达时形成相应视觉要求并生成新形象。保存完成的状态形象及必要的上下文说明，供后续故事再次使用，不预设固定状态类别或素材匹配表。

将新故事及其决定的状态和形象表达作为同一宠物的内部记录延续，按该宠物的唯一编号更新对应 Pet／Avatar；目标激活使用时即时刷新。对用户只呈现这段故事的文本与图像，具体表达与实际完成的变化和可用素材相符，不附带插件运行说明。
```

本任务的故事、状态表达与素材选择供内部执行和记录使用。[形象提示词](pet-appearance.zh-CN.md) 负责所需视觉表达，[故事输出提示词](pet-story-output.zh-CN.md) 负责最终对话呈现。故事图像和 Pet／Avatar 的状态形象按各自表达需要组织，具体形式由 Agent 决定。
