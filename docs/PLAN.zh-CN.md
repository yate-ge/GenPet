# GenPet v0.1 产品与实现方案

> 最新机制以 [先有蛋，身份在孵化时形成](MECHANISM.zh-CN.md) 为准。领养只生成不具象的蛋，完整幼体身份延迟到孵化时才解析。

## 目标

直接使用 Codex 原生 Pet 窗口，替换其中的角色。原生悬浮、拖动、任务状态、等待输入、完成检视等交互继续由 Codex 驱动。GenPet 插件负责生命周期、自动上下文、个体设计和图像生成素材管理。网页调试工具位于独立的 GenPet-Debugger 项目，不打入插件或源码发布包。

最新视觉方向是 Codex 内置 Pet 的像素画、深色描边和有限色阶。角色造型可以有机、柔软，但材质不是毛绒或写实 3D。所有角色和动作图由图像模型生成；代码仅提取、校验、组装和显示。

GenFaceUI 作为理论参考：统一的可生成设计空间与个性化实例、稳定身份和情境表达、设计者边界与用户干预。它不要求复刻原系统。长期成长效果是本项目的新假设，尚未经过研究验证。

## 三个时间尺度

| 时间 | 变化 | 保持不变 |
|---|---|---|
| 领养 | 根据近期活动与种子形成弱色调/抽象纹理线索，不决定幼体 | 同一家族的轮廓、动作语义、像素密度 |
| 5 小时 | 首次用孵化期经历解析身份并正向生成幼体；之后选择情境道具 | 出生前只有弱线索；出生后锁定已认可身份 |
| 每 24 小时 | 体态逐渐长大、表达倾向缓慢偏移、积累纪念细节 | 不重抽物种，不因离线退化 |
| 即时 | idle、左右拖拽动作、招手、跳跃、失败、等待、工作、检视、注视 | 完全服从 Codex 运行状态 |

时间以领养时刻为锚点；默认第 7 个完整成长日进入少年，第 21 天进入成熟。每日从孵化后计时。离线后补算，重复检查不重复成长，系统时钟回退不退龄。没有工作时长排行榜、连续打卡或健康惩罚。

## 自动个性化

默认读取本机最近 5 小时 Codex 用户消息，从活动线索区分构建、研究、创作、学习和休息；不读取系统指令、工具输出，也不把对话文本写入 GenPet 状态。每个任务限权，弱线索不硬分类。初始实现是本地规则分类，并非完整语义理解或用户人格推断。

活动类别只提供设计线索，随机种子提供个体差异。蛋壳签名不是完整生物基因：未知蛋期间没有耳形、脸或肢体方案，hatchIdentity 保持 null。真正的外观需要图像生成完成；设计方案、预制示例、已完成个性化素材在状态中分开。用户可以关闭读取、清除标签、改名字与陪伴偏好。

### 当前可执行的默认映射

| 自动识别的活动 | 蛋壳弱色调 | 5 小时情境道具 |
|---|---|---|
| 构建 | 极淡鼠尾草绿 | 小工具 |
| 研究 | 极淡天蓝 | 书本 |
| 创作 | 极淡桃色 | 画笔 |
| 学习 | 极淡紫 | 探索徽记 |
| 休息 | 极淡鼠尾草绿 | 靠枕 |
| 证据不足或类别并列 | 默认弱色调，保留随机细纹差异 | 不添加道具 |

这些对应关系是可改的视觉隐喻。领养种子仅在色相 ±8 范围与抽象纹样上形成蛋壳约束；附属结构等幼体特征在孵化边界才解析；图像模型的执行结果需要审核，种子不是模型提供的逐像素可复现保证。原生 Pet 用道具表达情境；场景目前只在诊断页显示，不宣称原生窗口已有完整场景切换。

## 图像管线

1. 读取设计请求和经认可的身份母版。
2. 用 Codex `imagegen` 生成当前成长/情境版本的母版。
3. 使用 `hatch-pet` 为每个原生动作生成独立行；只有左右移动在可镜像时允许确定性派生。
4. 提取为 192×208 单格，组装 8×11 v2 atlas，透明未使用格。
5. 检查尺寸、非空帧、透明、身份一致性、动作语义、16 注视方向和连续性。
6. 验证通过后原子切换素材；失败保留上一版本。

本地 Node 进程不能直接调用 Codex 内置 `imagegen`。图像任务由已安装插件 skill 在 Codex 中执行，自动周期执行由 Codex 原生 Scheduled Tasks 调度。不会把“生成请求已创建”记为“图像已生成”。

## 原生边界

支持的集成点是 Codex 自定义 Pet 目录、精灵图规范、插件 skills/MCP 和官方安装 CLI。不修改应用 bundle，不覆盖内置宠物素材。新素材写入同一自定义 Pet 身份。当前版本没有已验证的公开原生热刷新 API，而是通过本机调试通道作废宿主查询并核对实际显示摘要；通道不可用时不能声称自动换图完成。

## 可定制项

- **品牌角色**：名称、物种轮廓、像素密度、允许的色板。
- **身份锁定**：主色、纹样、眼形与标志物；哪些允许用户重新生成。
- **成长速度**：5 小时孵化、每日间隔、少年/成熟天数；成熟后装饰规则。
- **上下文映射**：研究→书本、构建→工具、创作→画笔、学习→探索徽记、休息→靠枕；可替换。
- **表达倾向**：沉静/好奇/活泼的权重与最大每日变化量。
- **数据范围**：当前设备、最近 5 小时、全部本地任务；未来可加项目白名单。
- **生成预算**：图像刷新频率、变更阈值、每日最多生成次数、失败重试策略。
- **研究条件**：固定宠物、仅情境变化、仅成长、成长与情境同时变化；需另行设计研究。

优先需要你最终确定的是角色家族、身份不变量、成长速度和生成成本预算。其余已有可运行默认值。
