# 领养之后的内容案例

2026-10-15 按 [开发计划](DEVELOPMENT_PLAN.zh-CN.md)「故事设计原则（2026-10-15 修订）」重写，用来讨论方向。五只宠物沿用 [领养旅程案例](ADOPTION_CASES.zh-CN.md)。每次的观察都是假设的；内容由人写出来说明方向，没有经过 Agent 实际运行。2026-10-10 的旧版在 git 历史里。

## 用户在哪里看到内容

1. **桌面上的宠物。** 平常是日常变化：穿的、戴的、拿的、正在做的事、它此刻的状态（困了、专注、刚旅行回来）、姿势、身边的一点环境，身体不变。成年以后偶尔会幻化：超越自然的一次大变身，过两天变回来。
2. **对话里的一条消息。** 定时检查的消息出现在定时任务所在的对话里；用命令调用时，出现在用户输入命令的对话里。消息用 Markdown 排版：可以有图（道具、家、成长后的样子），一句斜体的叙述，和一句它对用户说的话；也可以没有消息。

## 写法

- **故事 = 观察 → 反应 → 表达。** 每次先观察用户此刻的情境，再由它的性格和相处决定怎样回应，最后选择让用户看到什么。也可以这次不观察。
- **联系由它的行为体现。** 用户看到它的样子、它在做的事、它拿出来的东西，自己感受到和自己有关。不用旁白复述用户的事，不写「你还在忙」，不写「你做了 X，所以它也做了 X'」。
- **日常和幻化分清。** 身体不变的是日常：穿戴、拿的东西、在做的事、它的状态。幻化只在成年：用户连续三天以上保持同一种状态时，它可能以一次超越自然的变身来回应，选一个幻化对象（某种超自然的状态、一种能力、另一种形态），和它自己的配色、标志性器官和眼睛结合起来，一眼看得出变了、也认得出是它；仍然可爱，不评价用户，不拿熬夜、加班、情绪或健康作起因。两天内变回幻化前的样子，至少隔一周才会再有。
- **动作按它此刻的样子。** 桌面上的每个动作（待机、左右移动、点击）都按这次的样子和状态设计，不要求字面动作：睡着的它不会站起来跑，左右移动可以是翻身、转头，点击可以是伸个懒腰。
- **它在虚拟世界里。** 它做的事、给的东西都发生在它自己的世界里：在自己的家里陪着读、陪着画、陪着做饭，给用户一枚奖章、一碗汤、一张明信片这类虚拟物品，都自洽。不假装替用户做了现实里的事：不说「笔我帮你洗好了」「锅和刀都备好了」，也不写它凑到用户的锅边闻味道。它可以评论用户在会话里写的东西（比如菜谱的用量），因为它读得到。
- **看得懂。** 它做的事和给的东西，是人一看就懂的日常表达：陪着读书、做一枚奖章、寄一张明信片、带回一箱纪念品、说一句「加油」。不用要猜的象征（转齿轮、留空格、捡一颗石子）。
- **消息分清叙述和它说的话，用 Markdown 排版。** Codex 的对话会渲染 Markdown：图片在最前；叙述用斜体单独一段，用宠物的名字写它做了什么，一句、简短；它说的话单独一段，写成「**名字**：话」，像对白一样。叙述和说的话可以只有一样，以看得懂为准：图已经表达了它做什么时可以只说话，没有要说的话时可以只有叙述。「嘟囔着」「留言」这类说法放在叙述里。例如：

  > *小耳朵拿来一枚齿轮形状的小奖章，中间刻着“深夜高效工程师”。*
  >
  > **小耳朵**：给你！

- **叙述只补图里看不出的，说的话要有内容。** 不用文字重复状态图已经表达的意思（例如图上已经在陪着，就不写“陪着”）；它说的是真的对用户说的话。有内容是说出具体的一点（读完一本书，说喜欢哪一处），是它自己的感受，温和，不评判、不和用户的看法争。状态图已经说明一切、又没有要说的，就没有消息。
- **称呼用宠物的名字**，还没起名时用「它」。案例里的名字是示例，实际是用户起的。
- **阶段决定口吻。** 蛋只有叙述，不说话。幼年只说很短、很简单的话。少年和成年说完整的话，按性格和 memory。
- **不为故事而故事。** 主线是作为用户的新宠物的生活。领养旅程只作偶尔的回忆。
- **弱交互。** 可以直接对用户说话，不提问、不邀请、不预告下次。孵化时请用户起名是唯一例外。
- **敏感内容**（健康、财务、人际矛盾等）不使用、不保存。

每一条分五部分：

- **观察**：不给用户看，只保存一句简短的观察和来源；
- **桌面上的宠物**；
- **对话里的消息**；
- **不给用户看**：这次的情境和依据；
- **memory**。

## 情境和优先方向

| 情境 | 优先的故事 |
| --- | --- |
| 用户持续在忙 | 陪伴，形象和状态的变化；在家里做和用户当前事情有关的事 |
| 用户有节点：完成、开始、新变化、对它说过的话 | 回应：对用户说话，或给用户一样东西 |
| 用户在，但没什么新情况 | 在家里做和用户近况有关的事 |
| 很久没有动静 | 外出旅行、修整家 |
| 经历积累或到了最晚期限 | 成长，落在用户的真实节点上 |
| 用户连续三天以上保持同一种状态（只在成年） | 可能幻化：它自己好玩的回应，不评价用户 |

## 五个案例的差别

| 案例 | 宠物和关系 | 阶段 | 主要情境 |
| --- | --- | --- | --- |
| A | 耳廓狐，搭档 | 蛋 → 幼年 → 少年 | 用户连续几晚深夜写代码，卡住后修好；成长落在新项目开始那天 |
| B | 不倒翁，损友 | 少年 | 用户开着 Codex 三天没用，接着两天没开，然后回来 |
| C | 短尾乌贼，知音 | 少年 | 用户备考的一周；会话里出现敏感内容；考完后用户在 `/genpet-chat` 里说的话，下一次故事回应 |
| D | 草莓寄居蟹，互补 | 少年 → 成年 | 用户同时赶三个稿子，周末停下来，最后全部交付 |
| E | 神雕，陪练 | 成年 | 用户连着几天一版一版改红烧肉，它幻化成火羽，两天后变回来；用户用 `/genpet-grow` 让它幻化，先确认；三个月后 memory 让它说话的方式变了 |

最后另有三节：幻化怎样算、怎样不算；只有文字的故事什么时候可以用；常见的错误写法。

## 案例 A：耳廓狐，深夜写代码的一周

沿用领养案例 1。关系是搭档。它耳朵大，爱听东西哪里不对。假设领养发生在周一上午 10 点，孵化后用户给它起名「小耳朵」（示例名）。

**周一 15:00，领养后 5 小时**

- 观察：没有看。孵化到了最晚时间。
- 桌面上的宠物：从蛋换成刚孵化的小耳廓狐，整套新形象。耳朵比脸还大，一只耷拉着。
- 对话里的消息：

  > 〔图片〕它的新样子：刚孵化的小耳廓狐，一只耳朵耷拉着。
  >
  > 〔图片〕它的家：修理铺柜台下面的一只旧工具箱，垫着棉布。
  >
  > *壳裂开了，它钻出来，先竖起那只大耳朵听了听外面。*
  >
  > *它还没有名字。你想叫它什么？*

- 不给用户看：成长，加家的变化。
- memory：更新，记下它孵化了。

**周二 01:00**

- 观察：晚上 10 点起一直在同一个项目的会话里，最后一条刚过去几分钟。
- 桌面上的宠物：换成裹着一小块毯子、坐在一盏小台灯旁边的样子，眼睛快闭上了，还撑着。动作按犯困设计：待机是脑袋一点一点；左右移动是裹着毯子慢慢挪；点击是猛地睁大眼睛，又慢慢眯回去。
- 对话里的消息：

  > *小耳朵揉了揉眼睛。*
  >
  > **小耳朵**：不困……再陪你一会儿。

- 不给用户看：陪伴，形象变化。图上已经是陪着的样子，文字是它对用户说的话。幼年只说很短的话。犯困是它自己的样子，不是在说用户熬夜；深夜过去后的下一次故事就换掉。
- memory：更新，第 1 次经历。加上：它孵化后的第一个深夜，用户一直在忙，它裹着毯子在灯边陪着。

**周三 23:00**

- 观察：两天里同一个项目的会话名称都是同一个报错，今晚还在查。
- 桌面上的宠物：换成趴在地上、举着一个比它头还大的放大镜在找东西的样子，耳朵贴着地。
- 对话里的消息：

  > *小耳朵趴在地上举着放大镜，嘴里一直在嘟囔。*
  >
  > **小耳朵**：虫子在哪里……

- 不给用户看：陪伴，形象变化。用户在找 bug，它在自己那边帮着“找虫子”。程序员一看就懂。
- memory：更新，第 2 次经历。加上：用户被一个 bug 卡了两天，它举着放大镜帮着找虫子。

**周四 10:00**

- 观察：早上新开了一个会话，名称是「修复后发布」，那个报错没有再出现。
- 桌面上的宠物：换成两只耳朵都竖着、胸前挂着一枚小奖章的样子。
- 对话里的消息：

  > 〔图片〕一枚齿轮形状的小奖章，红色绶带，中间刻着「深夜高效工程师」。
  >
  > *小耳朵拿来一枚齿轮形状的小奖章，中间刻着“深夜高效工程师”。*
  >
  > **小耳朵**：给你！

- 不给用户看：回应，故事物件。问题修好了，它给用户做了一枚奖章。幼年只说两个字，奖章上的字把意思说清楚了。它自己也挂了一枚一样的。
- memory：更新，第 3 次经历。加上：用户修好那个 bug 的早上，它给用户做了一枚「深夜高效工程师」奖章。

**周六、周日**

- 观察：两天都没有会话，Codex 开着。
- 桌面上的宠物：换成摊在工具箱里睡大觉的样子，奖章还挂在胸前。整套动作按睡觉设计：待机是肚子一起一伏；左右移动是迷糊地翻个身朝左、朝右；点击是伸个懒腰又躺回去。
- 对话里的消息：没有。
- 不给用户看：自己的生活。两天不算久，不用外出；用户休息，它也睡个够。睡觉跟时间有关，用户回来后的下一次故事就换掉。
- memory：不更新。

**下周一 09:00，经历攒到 5 次之后**

- 观察：早上新开了一个项目，会话名称是新的。
- 桌面上的宠物：换成少年的整套新形象。两只耳朵都竖着，比以前大了一圈。
- 对话里的消息：

  > 〔图片〕它的新样子：少年的耳廓狐，两只大耳朵都竖着。
  >
  > *小耳朵长成了少年，两只大耳朵都竖了起来。*
  >
  > **小耳朵**：我长大了，耳朵能听得更远了。新项目开工，我陪着你。

- 不给用户看：成长，落在用户的真实节点（新项目开始）上。少年开始说整句。
- memory：更新。重写后的全文：

> 它是在收摊后的夜市被领回来的，和用户是搭档。用户常在深夜写代码，它会裹着毯子在灯边陪着。用户被一个 bug 卡了两天，它举着放大镜帮着找；修好那天，它给用户做了一枚「深夜高效工程师」奖章。用户开新项目那天，它长成了少年。它说话很短，爱说自己听到了什么。

## 案例 B：不倒翁，用户不在的日子

沿用领养案例 2。关系是损友，嘴硬、爱逞强，怎么推都不倒。它已经是少年，名字叫「墩墩」（示例名）。

**周三 15:00**

- 观察：上一次会话是周日晚上；Codex 一直开着，定时检查照常运行，但三天没有新的会话。
- 桌面上的宠物：换成戴着一顶小草帽、拖着一只小行李箱的样子。
- 对话里的消息：

  > *墩墩给你留了言。*
  >
  > **墩墩**：出门旅行几天，去海边。

- 不给用户看：不在的日子，外出。用户好几天不用，它就自己出门了。
- memory：不更新。

**周三 20:00**

- 观察：仍然没有新的会话。
- 桌面上的宠物：不变。
- 对话里的消息：

  > 〔图片〕一张明信片：正面是海边的小灯塔，背面歪歪扭扭写着「海风很大，我没倒。」
  >
  > *墩墩从海边给你寄来一张明信片，请查收。*

- 不给用户看：不在的日子，故事物件。明信片上那句是它损友式的逞强。
- memory：更新。加上：用户好几天没来，它去海边旅行，寄回一张明信片。

**周四、周五**

- 观察：Codex 没有开，定时检查不会运行（调度器在 Codex 桌面 App 里，App 不开就不跑）。
- 桌面上的宠物：不变，用户也看不到。
- 不给用户看：没有检查，就没有内容。

**周六 10:00，用户回来了**

- 观察：这次检查是 Codex 打开后补跑的一次（定时任务错过的几次不会逐个补，只补这一次）；距上一次检查两天多，距上一次会话将近六天。用户可能还没开新会话，刚打开 Codex 这件事本身就是回来了。
- 桌面上的宠物：换回不戴草帽的样子，坐在打开的行李箱旁边。
- 对话里的消息：

  > 〔图片〕一只打开的行李箱，塞满了从海边带回来的东西：一罐沙子、几个贝壳、一顶晒褪色的草帽、一个灯塔形状的小摆件。
  >
  > *墩墩拖着行李箱回来了，打开给你看。*
  >
  > **墩墩**：我回来了！给你带了一箱海边的东西。

- 不给用户看：不在的日子，旅行带回来的东西。它不问用户去了哪里，也不说一直在等。
- memory：更新。加上：用户有六天没来，它去海边玩了一趟，带回一箱纪念品。

**周日 15:00**

- 观察：用户回来后照常在用。
- 桌面上的宠物：不变。
- 对话里的消息：

  > 〔图片〕它的家：架子上摆好了贝壳和灯塔摆件，那罐沙子放在窗台上，草帽挂在墙上。
  >
  > *墩墩把纪念品一件件摆好。*
  >
  > **墩墩**：海边搬回家了。

- 不给用户看：修整家。旅行带回来的东西放进了家里。
- memory：不更新。

## 案例 C：短尾乌贼，用户备考的一周

沿用领养案例 3。用户是学生，爱诗词。关系是知音。它是少年，名字叫「墨墨」（示例名）。

**周一 22:00**

- 观察：这周的会话多是整理复习笔记、刷题，每天到深夜。
- 桌面上的宠物：换成戴一副小圆眼镜、几条腕足抱着一本比它还大的书、埋头读的样子，身边一盏小灯。
- 对话里的消息：

  > *墨墨推了推小眼镜，小声说。*
  >
  > **墨墨**：加油。

- 不给用户看：陪伴，形象变化。图上是它陪着读书，文字是它对用户说的话。
- memory：更新。加上：用户备考的那一周，它也抱着书陪着读。

**周三 23:30**

- 观察：今晚的会话里有用户和室友争吵的内容。
- 桌面上的宠物：不变，还在读书。
- 对话里的消息：没有。
- 不给用户看：这是人际矛盾，不使用，也不保存。这次照旧陪着，不做任何回应。
- memory：不更新。那条内容不进 memory。

**周五 07:00**

- 观察：会话名称是「明天考试最后过一遍」。
- 桌面上的宠物：换成书合上了、压在腕足下面、它自己蜷在书上睡着的样子。动作按睡着设计：待机是墨囊一鼓一鼓；左右移动是腕足在书页上翻一下；点击是半睁一只眼，又睡过去。
- 对话里的消息：没有。
- 不给用户看：陪伴。最后一天它先读累了，睡着了。
- memory：不更新。

**下周一 12:00**

- 观察：考试那几天之后，会话变成了「暑假想读的书单」。
- 桌面上的宠物：不变。
- 对话里的消息：

  > 〔图片〕它的家：书架最上面一层多了那本大书，书脊朝外，写着《海底的四季》，旁边空着几格。
  >
  > *墨墨把陪读的那本大书放上了书架。*
  >
  > **墨墨**：这本读完啦。最后一章写冬天的海，很安静，我读了两遍。

- 不给用户看：回应，家的变化。考完了，它把陪读的书收上书架。没有写「你考完了」。它说的是读这本书自己喜欢的地方，是它的感受，不评价、不讲道理，也不和用户的看法比。
- memory：更新。加上：考完那天，它把陪读的书放上了书架。

**下周二，用户在 `/genpet-chat` 里和它聊天**

- 用户说：「考完了，想去海边走走。」
- 墨墨回答：

  > **墨墨**：海边好呀。冬天的海很安静，夏天的海很吵，我都喜欢。

- 不给用户看：对话。对话不当场改变它，样子、家和 memory 都不变；这句话值得记，作为一条用户说过的话保存，下一次故事读得到。

**下周三 15:00**

- 观察：会话照常；上一次对话里用户说想去海边走走。
- 桌面上的宠物：不变。
- 对话里的消息：

  > 〔图片〕一枚小海螺，螺口贴着一张小纸条：「放在耳边，能听到海。」
  >
  > *墨墨从自己的海里捡来一枚小海螺。*
  >
  > **墨墨**：先听一会儿海。

- 不给用户看：回应，故事物件。回应的是用户在对话里说过的话；海螺是它世界里的虚拟物品。它不追问用户什么时候去、去哪里，也不替用户订行程。
- memory：更新。加上：用户说考完想去海边，它从自己的海里捡来一枚海螺。

## 案例 D：草莓寄居蟹，用户赶稿的一周

沿用领养案例 4。用户是插画师，常同时接几个稿子。关系是互补：用户忙的时候，它在旁边把慢的、照顾人的那一面接过来。它是少年，这个阶段已经有 3 次经历，名字叫「小莓」（示例名）。

**周二 15:00**

- 观察：今天同时开着三个不同客户的会话，从早上到现在没停。
- 桌面上的宠物：换成戴着袖套、坐在一块小画板前、用大钳夹着一支小笔慢慢涂色的样子。
- 对话里的消息：

  > *小莓给草莓点上最后一颗籽。*
  >
  > **小莓**：一颗草莓，画了一下午。慢慢画也挺好。

- 不给用户看：陪伴，形象变化。用户在赶稿，它在自己的家里也画画，画得很慢，是互补的那一面。它不假装替用户做了现实里的事（洗笔、收拾桌子）。
- memory：不更新。

**周四 23:00**

- 观察：还是三个会话轮流在用，到深夜没停。
- 桌面上的宠物：不变。
- 对话里的消息：

  > 〔图片〕一碗冒着热气的海带汤，放在一个小托盘上，旁边一把小勺。
  >
  > *小莓端来一碗冒着热气的海带汤。*
  >
  > **小莓**：趁热喝。

- 不给用户看：陪伴，故事物件。深夜还在画，它端来一碗汤。
- memory：更新，第 4 次经历。加上：用户赶三个稿子的那周，它深夜给用户端了一碗海带汤。

**周六 15:00**

- 观察：周六没有会话。前几天很忙。
- 桌面上的宠物：换成在家门口晒太阳、四脚朝天的样子。动作按晒太阳设计：左右移动是翻个身换一面晒；点击是举起大钳伸个懒腰。
- 对话里的消息：

  > *小莓翻过身晒着壳，懒洋洋的。*
  >
  > **小莓**：今天休息！

- 不给用户看：自己的生活。用户停下来了，它也放假。
- memory：不更新。

**下周一 18:00**

- 观察：三个会话的名称都改成了「交付」相关。
- 桌面上的宠物：换成成年的整套新形象，背着一只更大的新壳。
- 对话里的消息：

  > 〔图片〕它的新样子：成年的寄居蟹，背着一只更大的新壳。
  >
  > 〔图片〕它的家：架子上多了一只小一号的旧壳。
  >
  > *小莓换上了一只更大的新壳，把旧壳摆上了架子。*
  >
  > **小莓**：交稿快乐！换个大壳庆祝一下。

- 不给用户看：成长，第 5 次经历，正好落在用户三个稿子都交付的节点上。它直接为用户庆祝。
- memory：更新。加上：用户交付三个稿子的那天，它换了新壳，长成了成年。

## 案例 E：神雕，改到第四版的红烧肉

沿用领养案例 5。用户爱研究菜谱。关系是陪练：它盯着用户练手、爱挑毛病，也会撸起袖子一起动手。它已经成年，身体不再长，之后的变化来自 memory。名字叫「阿雕」（示例名）。

**周六，用户输入 `/genpet-story`**

- 观察：这次是用户主动叫它。这周的会话都在写代码，今天新开了一个会话在查红烧肉的做法。
- 桌面上的宠物：换成系着围裙、在自己的小灶台边颠勺的样子。
- 对话里的消息：

  > *阿雕把自己的灶也点上了。*
  >
  > **阿雕**：做个大餐，犒劳一下自己。

- 不给用户看：陪伴，形象变化，出现在用户输入命令的对话里。忙完一周，用户想做顿好的；陪练的方式是在自己的灶台边也做一顿。它不替用户准备现实里的锅和刀。
- memory：不更新。

**之后一周的定时检查**

- 观察：连着四天的会话都在改同一道红烧肉的方子，今天改到了第四版。
- 桌面上的宠物：幻化成火羽阿雕的整套新形象：羽毛变成暖橙色，羽尖跳着小火苗，冠羽卷成一缕炊烟，眼睛和神情还是阿雕。整套动作按火羽设计：待机时火苗轻轻摇；左右移动是踱步，火苗跟着往后飘；点击时扇一下翅膀，火苗蹿高一点。
- 对话里的消息：

  > 〔图片〕它的新样子：羽尖冒着小火苗的火羽阿雕。
  >
  > *阿雕在自己的灶台边守了几天，今天羽毛尖上冒出了小火苗。*
  >
  > **阿雕**：火候我现在自己带着了。第四版，稳。

- 不给用户看：幻化，进入。契机是用户连续四天都在改同一道菜的方子（同一种状态持续三天以上）。幻化对象是火：羽毛的颜色和质感大变，多了会冒火的能力；冠羽的形状、配色和眼睛保留，一眼认得出是阿雕。这是它自己好玩的回应，不评价用户。
- memory：更新。加上：用户连着几天改红烧肉方子的那阵，它幻化成了火羽，一扇翅膀就能点着自己的灶。

**两天之内**

- 观察：没有看。幻化到了时限。
- 桌面上的宠物：换回幻化前那套系着围裙的样子，复用已有的图。
- 对话里的消息：

  > *阿雕的火苗一点点收了回去，又系上了围裙。*
  >
  > **阿雕**：火收起来了，第四版的火候我记着。

- 不给用户看：幻化结束，回到幻化前的日常样子。它不问那锅肉做得怎么样，也不替用户写结果。至少一周内不会再幻化。
- memory：不更新。

**一个月后，用户输入 `/genpet-grow`**

- 确认（用户看到的一句话）：「阿雕已经成年，这次会让它幻化一次，两天内变回来。要现在开始吗？」用户回答「好」。
- 桌面上的宠物：幻化成 Q 版人形的整套新形象：圆脸、大眼睛的小厨师，头发是阿雕羽毛的棕白两色，头顶那撮冠羽变成一缕翘起的呆毛，眼睛还是金色，围裙也还系着。动作按小厨师设计：待机是掂一掂小锅；左右移动是小跑几步；点击是把锅铲举起来转一圈。
- 对话里的消息：

  > 〔图片〕它的新样子：Q 版人形的小厨师阿雕，头顶一缕翘起的冠羽。
  >
  > *阿雕摇身一变，成了一个系着围裙的小厨师，头顶那撮冠羽还翘着。*
  >
  > **阿雕**：两条腿掂锅，比一只爪子稳。

- 不给用户看：幻化，由用户的明确请求触发，执行前确认过。明确请求不受「两次至少隔一周」限制。幻化对象是人形：圆润的 Q 版，不性感化，不像任何真实的人；冠羽、配色和眼睛保留，一眼认得出是阿雕。原因记为用户请求，不当作用户生活里的事。
- memory：更新。加上：用户叫它幻化那天，它变成了一个系围裙的小厨师。

如果用户在它幻化期间再输入 `/genpet-grow`，确认那一句是「阿雕现在是幻化的样子，这次会让它变回原来的样子。要现在变回来吗？」，确认后换回幻化前的日常样子，复用已有的图。

**三个月以后**

- 观察：会话又在改红烧肉的做法，这次加了陈皮。
- 桌面上的宠物：换成系着围裙、翻着自己那本记满批注的小菜谱的样子。
- 对话里的消息：

  > *阿雕翻到自己记下第四版的那一页。*
  >
  > **阿雕**：陈皮放少了。上回第四版那个量刚好，我记着呢。

- 不给用户看：回应。它记得用户以前做过第四版（memory），按陪练的关系直接挑毛病。和刚成年时只会说几个字相比，话变多了，也会拿以前的事来比。
- memory：更新。相处一段改成：它会把用户以前的做法记下来，拿出来比。

## 幻化：算和不算

幻化只在成年。先有契机（用户连续三天以上保持同一种状态，或用户用 `/genpet-grow` 明确要求），再选一个幻化对象，和它自己的身份核心结合。下面的对象只是例子，实际由 Agent 按这只宠物和这次的契机去选。

**算幻化（例子）**

| 宠物 | 契机 | 幻化对象 | 新样子 | 为什么认得出是它 |
| --- | --- | --- | --- | --- |
| 小耳朵（耳廓狐，成年） | 用户连着四天都在调同一段音频 | 光：一种超自然的状态 | 全身变成半透明的淡金色，大耳朵边缘一圈圈泛着声波一样的光 | 耳朵的形状和那只耷拉过的耳尖还在 |
| 墩墩（不倒翁，成年） | 用户连着三天都在整理旅行照片 | 云：一种能力的显现 | 身体变成一团圆滚滚的白云，能慢慢飘起来，底部还是不倒翁的弧度 | 脸上的红晕和那顶褪色草帽 |
| 墨墨（短尾乌贼，成年） | 用户连着几天都在读同一本长篇小说 | 另一种动物：海马 | 变成一只小海马，卷着尾巴，背上还是乌贼的斑点和颜色 | 小圆眼镜和墨色斑点 |
| 阿雕（神雕，成年） | 用户连着四天改同一道菜的方子 | 火 | 羽尖跳着小火苗，冠羽卷成一缕炊烟 | 冠羽的形状和金色的眼睛 |

**不算幻化，或不能这样幻化**

| 写法 | 问题 | 应该怎样 |
| --- | --- | --- |
| 戴上一顶厨师帽、换一身亮片衣服 | 身体没变，是日常变化 | 想做幻化，就让轮廓、构造或质感真正变化 |
| 冠羽竖起来像一顶帽子 | 变化太小，像换了个姿势 | 一眼看得出的大变化，例如变成火羽 |
| 用户连着熬夜，它就黑化、变得阴沉 | 拿熬夜作起因，在评价用户 | 契机只看用户保持同一种状态；幻化是它自己好玩的回应。暗色的幻化可以有，但只是酷，起因不是熬夜 |
| 用户最近状态不好，它变得病恹恹、缠着绷带 | 映射用户的健康和情绪，也不让人愉快 | 不出现疾病、受伤；不映射用户的状态 |
| 长出獠牙、血红眼睛的恶魔形态 | 吓人，越过安全护栏 | 仍然可爱、让人愉快；拿不准就换一个对象 |
| 幻化成某部动画里的具体角色，或很像真实的某个人 | 照搬别人的角色，像真实的人 | 用自己的身份核心去结合对象的特点 |
| 用户只是今天在做一件事，它就幻化 | 没有持续三天以上的契机 | 平常的变化交给日常 |
| 刚变回来两天，又幻化成别的 | 两次幻化至少隔一周 | 等一周以后；用户明确用 `/genpet-grow` 时例外 |

## 只有文字的故事

只有文字的故事必须能对应到这次观察到的、或者以前一起经历过的、和用户有关的事，最多连续 2 次。这一类桌面上的宠物都不变。

- **小耳朵（耳廓狐，少年）。** 观察：用户把拖了两周的那个功能合并了。消息：*小耳朵竖起耳朵。* **小耳朵**：合并了！我听见啦。
- **阿雕（神雕，成年）。** 观察：用户又在改同一道菜。消息：**阿雕**：陈皮放少了。上回第四版那个量刚好，我记着呢。
- **墨墨（短尾乌贼，少年）。** 观察：考试那几天之后，用户在列暑假书单。消息：**墨墨**：书单里那本诗集，我也想读。

**不能用只有文字的情况：**

- 这次没有观察，宠物记录里也没有合适的旧事可以对应。
- 这次不能只发文字，改成日常变化、故事物件或家的变化。
- 反例：「它今天在家里转了一圈，找到一个舒服的角落睡着了。」这段只讲它自己，对应不到任何和用户有关的事。

## 常见的错误写法

这些是讨论和测试里实际出现过、或容易写出来的写法。

| 错误写法 | 问题 | 改成 |
| --- | --- | --- |
| **小莓**：笔我帮你洗好了。 | 假装替用户做了现实里的事。它在虚拟世界里，替用户洗笔没有意义 | 它在自己的家里也慢慢画一张：**小莓**：一颗草莓，画了一下午。慢慢画也挺好。 |
| **阿雕**：家伙都备好了，等你开火。 | 假装替用户准备了现实里的锅和刀 | 它在自己的灶台边也做一顿：**阿雕**：做个大餐，犒劳一下自己。 |
| 它摆了一桌宴客菜等用户回来 | 把日常的事放大成了大场面 | 日常的事用日常的方式：做一顿，或端来一碗汤 |
| 它凑到用户的锅边闻了闻 | 写它走进了用户的现实 | 它闻的是自己灶上的锅 |
| *你还在忙，它也陪着忙。* | 用旁白复述用户的事，写成「你做了 X，所以它也做了 X'」 | 让图上的样子去陪着；有话就是它直接对用户说的一句 |
| **墨墨**：这本读完啦。 | 没有内容 | 说出具体的一点，是它自己的感受：**墨墨**：这本读完啦。最后一章写冬天的海，很安静，我读了两遍。 |
| **墨墨**：这本书的观点其实不对。 | 评判、和用户的看法争 | 说它自己喜欢哪一处，温和 |
| **小耳朵**：别熬夜了，早点睡。 | 评价用户的生活方式，也碰到了健康 | 它陪着就好：裹着毯子在灯边打瞌睡 |
| 它转了三圈齿轮、在桌上留了一个空格 | 要猜的象征，要读过前史才懂 | 一看就懂的举动和物件：一枚奖章、一张明信片 |
| **墩墩**：你什么时候回来？ | 向用户提问，暗示要回应 | 留一句自己的话：**墩墩**：出门旅行几天，去海边。 |
| 睡着的它在走动的动作里站起来跑 | 动作没按它此刻的样子设计 | 左右移动是翻个身、转个头，点击是伸个懒腰 |
