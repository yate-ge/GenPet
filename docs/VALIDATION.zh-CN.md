## 既有图像证据

官方原生 V2 协议沿用 57 个标准动作帧、16 个方向姿态和额外中性格；本轮未添加动作类型、未改官方拟合与验证脚本。素材结构和既有视觉检查见 [视觉验证](VISUAL_VERIFICATION.zh-CN.md) 及 `assets/pets/*/` 中的报告。既有离线 Moss 成长样本不是当前真实宠物的长大证据。

当前真实宠物已完成首次孵化；空手/画笔/工具等部分状态和同一个原生条目的无感切换有用户确认。不同道具及成长阶段不会建立第二个原生条目。更早文档中“仍是蛋”“尚未自动刷新”的结论属于此前时间点，已由上述最新验证取代。

## 尚需验证

- 不同**真实用户**的最终图集能否被稳定认出，活动映射是否可理解和被认可。当前代码统计与生成对照只覆盖合成样本。
- 当前真实角色在实际成长到第 1、7、21 日时的当时情境完整 V2 图集、独立视线盲评、动作连续性与宿主显示。第 1 日已有空手隔离候选，第 21 日只有概念肖像；均不能替代到期阶段的验收与显示确认。
- 三条新命令在原生界面中由用户逐一触发的完整流程：调用 → 内置 imagegen → 官方 QA → 同 ID 安装 → displayStatus confirmed。MCP 工具链和真实身份候选的隔离流程已通过，但没有为了验收命令而重置或加龄用户的真实宠物。
- 再次运行、长时间离线及未来 Codex 版本的兼容性。自动刷新依赖本地调试通道，不是公开稳定的 Pet 插件热重载 API。

真实用户映射、成长和状态的分层实验条件见[验证方案](EVALUATION_PROTOCOL.zh-CN.md)；尚未采集参与者数据。

五小时孵化/情境边界与每日成长是逻辑时间；调度延迟、图像生成、验收和可见刷新分别计时。正常成长使用真实时钟；显式 grow 加速的宠物应标记为调试样本。详见 [调试命令](DEBUG_COMMANDS.zh-CN.md)。
