# 可定制项与当前默认值

普通领养无需填写问卷。插件默认读取本机 Codex 近期用户消息，提取有限活动标签；下面是设计者可以调整的范围，不是要求每个用户先做的设置。

新领养会在宠物状态与图像请求中记录 `adoptionTrace`：五类活动的任务计数、是否有唯一主导类别、以及显式覆盖了哪些配置字段。它不包含消息原文、会话路径或人格推断；旧宠物不会被追溯重算。图集请求 ID 仍只由当前视觉设计决定，添加这份解释记录不会重生已有角色。

| 设计决策 | 当前默认 | 修改位置 |
|---|---|---|
| 初始蛋的共同风格 | 普通卵形、乳白/暖灰、极淡抽象色点，无脸或物种线索 | `src/art.ts` 中蛋阶段提示词 |
| 个体线索强度 | 约 5–10% 表面带微弱色调和纹样；以种子产生差异 | `src/art.ts`、`src/core.ts` |
| 可生成的角色范围 | 圆润像素生物；round/pear/bean 身体和 buds/leaflets/soft-fins 附属结构 | `src/core.ts` 的 `resolveHatchIdentity` |
| 活动对出生的影响 | 主体由种子决定；部分参数最多 ±0.06 的偏置，不等于图像只有 6% 变化 | 同上 |
| 成长节奏 | 5 小时孵化；之后每 24 小时增加成长日；第 7 日少年、第 21 日成熟 | `config/policy.json`，仅影响新领养 |
| 长大的表达 | 身体比例逐渐成熟、表达倾向、小纪念细节；保持同一个体 | `src/core.ts`、`src/art.ts` |
| 情境更新 | 每 5 小时按已关闭窗口选择小道具；不把完整背景画入透明原生 sprite | 活动映射在 `src/core.ts` |
| 自动读取范围 | 本地 Codex 用户消息；排除系统、工具输出和子代理记录；不保存聊天原文 | `src/context.ts` |
| 生成频率与费用控制 | 只生成当前有变化的设计，不补画错过的每天；每行至多两次修复后保留旧图 | `skills/genpet/SKILL.md` 与自动化设置 |

用户随时可通过 `genpet_configure` 关闭读取、暂停自动图像生成、冻结装扮或改名，通过 `genpet_clear_context` 清除派生记录。关闭读取不会停止按时间正常成长。表达倾向属于角色设计参数，不是对用户人格或心理状态的判断。

建议先用这组默认值进行演示，再优先决定两件事：角色形态范围是否够丰富，以及日常更新是否需要更低的生成频率。原生动作表、图集格子数和播放时序属于 Codex 兼容协议，不作为自由设计参数。
