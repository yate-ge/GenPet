## 缺项与限制

- 6 个 evolution 单元在保持空状态 `state=""` 时被非空字符串合同拒绝：`01/long-gap`、`01/life-change`、`05/interest-change`、`07/grow-juvenile`、`07/grow-adult`、`10/grow-adult`。本轮记录问题，尚未修改代码或重跑。
- 完整流程共 17 个用例/分支，9 个下游受阻，实际生成 16 篇故事和 8 份 output 结果。显式成长请求在部分虚构夹具中被误判；受阻分支的故事只代表已有测试稿，不能算完成 Pet 更新。
- 两个成人阶段种子用例形成了特殊变化计划，但它们是反事实补测，不能证明此前成长链路成功。
- `07/independent-after-special` 没有实际故事正文和配图，未计入 82 篇。10 个新增多样性个体的领养相遇没有单独蛋图，部分变化分支也缺图。PDF 逐篇说明缺图或使用已有身份图的情况。
- 61 张原图及对应小图（共 122 个 PNG）保留在本地 `output/agent-tests/2026-10-03-run1/`。PDF 展示候选原图的排版版本；本 Git 归档不包含独立原始 PNG 或小图文件。已有小图中的 `diversity10/08`、`09` 将方图缩为 192×208，产生约 8.3% 比例拉伸，不能作为合格缩小展示证据。
- 合同有效仅说明结构检查通过。以上样本是固定场景探索，不是成功率估计；未确认所有代理使用相同模型。实际宿主显示、即时刷新、动画图集、安装和 M6 没有验证。
- 没有读取或修改用户的真实 Pet、Avatar、定时任务。所有变化均是测试计划；没有执行真实外观更新。
