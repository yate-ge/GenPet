## 需要保留的问题

1. **严格一周上限未满足。** Seed上次特殊形态于10月26日13:00上海时间结束，应最迟11月2日13:00进入；本轮仅在16:00执行，晚3小时。边界探针证明growth在13:00正确返回enter-special且已有due故事；这是本轮采样排期造成的端到端覆盖缺口，不能据此声称自动调度准时，也不能改比较日期掩盖结果。
2. **时间措辞和因果表达。** 第07篇周一用“这周”回顾上周事件有歧义；第06篇先试“新做的帽子”再交代制帽，倒叙提示不足。原文保留，未把事后改写当原始通过结果。
3. **篇章结构重复。** 多篇采用“你想……→行动→收纳”，媒介不同不等于叙事结构不同；01、08独立生活和10—12旧物重访有所改善。具体原文见独立检查。
4. **7张失败图片候选全部保留。** 照片前两版缺角位置错误/遗漏；空蜕前两版六足不可辨/爪端抓空；漫画前两版末格未改变躯体方向；家全景首版替换了照片内容、藏品形状与纸叠放。修订后7张接受图入库，不将初稿计为视觉通过。
5. **继承的前史问题。** Seed幼年故事出现完整有意义对白，与阶段限制不符。本轮12篇均成年，未修写原历史；该seed不能作为幼年语言边界的正例。

## 复核入口

在仓库根目录安装依赖后执行：

```powershell
node node_modules/tsx/dist/cli.mjs docs/evidence/2026-10-03-single-pet-14-days/probe-time.ts
node node_modules/tsx/dist/cli.mjs docs/evidence/2026-10-03-single-pet-14-days/verify-results.ts
```

`verify-results.ts`只读本目录证据，重验合同、实际历史/状态/复用及归档哈希；不接触用户Pet。`helper.ts`是本轮隔离运行入口，完整Store重放需复制并重定位种子资源。[manifest.json](manifest.json)列出接受素材、图片评审路径及归档哈希。[verification-results.json](verification-results.json)保存本轮实际复核输出。
