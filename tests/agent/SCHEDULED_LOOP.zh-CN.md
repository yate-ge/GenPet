# 真实宿主的定时循环

本测试补足代码与文字模拟不能证明的部分，对应 S14–S17、E3、U1、M7 和 D9–D11。完整要求见 [开发计划](../../docs/DEVELOPMENT_PLAN.zh-CN.md) 与 [Agent 套件](README.zh-CN.md)。默认桌面写故事，Dots 不另开并发故事来源。

## 分开环境

工程与单元测试使用隔离 GENPET_DATA_DIR/CODEX_HOME；这能证明文件和协议，不能证明真实客户端显示。真实宿主测试使用专属测试 Pet、核对 cloud ID 与专属任务引用，用户 Pet/任务不改。宿主能否把测试目录带进任务必须实际确认；不能时此项留未验证，不能移到真实用户记录凑通过。

安装、重装和只读探查不创建定时任务。已有授权的专属测试循环可建立一次任务，所有过程、快照和输出保留上传 Google Drive。

## 运行

1. 建独立数据与明确 test ID，完成已确认的测试领养，保存任务引用。
2. 宿主支持「立即运行」时，分别测试首次到期、同段重试、有未完成作业与恢复；自动触发和真实五小时节奏另外记录。
3. 未完成故事查看真实活跃句柄后再决定恢复，保持已保存步骤/已接受图与上传目标；回读超时不重启生成。
4. sleep/stop/切换的时间测试分开。未激活暂停截止，激活关机保留实际经过的时间，故事中途改选仍完成原 Pet。
5. Dots 消费同 cloud ID。主环境移交停旧任务、导出/导入完整目录、核对后开启新任务，测试中断及反向移交，不双写。

按 runtime 实际命令和宿主工具执行，不能用模拟 updated:true 证明上传、用 selection 回读证明显示，不能以 CODEX_HOME 的隔离文件成功证明真实 IPC。若宿主缺接口，继续独立工作，准确保留缺口与唯一所需外部动作。
