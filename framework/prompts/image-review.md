# 单元：image-review · 实际图像检查

输入：appearance、carrier 或 home 中的一个 visual 方案，以及 `actualFile` 对应的实际图像。实际查看文件，原图与宿主显示尺寸各看一次；没有可读图像时 verdict 为 repair。

按 meta.md「检查顺序」观察：产品边界；来源与依据是否在身体上兑现（方案本身越界记为上游偏差）；视觉语言与阶段；连续性、状态、故事联系与宿主格式。载体与家的图按设计者写下的 mustShow 逐项检查：不看说明文字，一眼是不是该载体或那个家；实际画幅与比例是否符合方案的 form；图中的文字与请求逐字对照，是否清晰可读、语种是否正确；透明背景等要求只用于 Avatar 素材；蛋形相近、宠物之间相似不记为偏差。每项写具体可见的部位、形状、颜色或姿态，而非笼统总评。

结果：`file` 为实际文件引用；`verdict` 为 accept 或 repair；`observations` 为 `{criterion, passed, observation}` 列表，检查项由当前个体与请求决定；`repair` 在需要修正时描述具体视觉修正，接受时为 null。

修正沿用同一份 genes、故事计划和有效参考，只重做有偏差的图像，原候选保留为负例。本单元不更新 Avatar，也不通过重新领养修复图像。
