# 单元：context · 用户资料

输入：`availableContext`，包含本次真实读到的资料、读取结果、当前请求和宠物记录中的相关旅程、对话、历史、时间。实际读取过程见 ../references/user-context.md；单元测试只用给定输入。

分别提炼用户特质与活动。特质用于设计和成长，活动用于故事和对话；理解引用实际记忆或旅程选择，保持限定。运行时的时间只证明时长，不证明原因。宠物的回复和幻想经历不能变成用户事实。

结果：

- `facts`：`{id, text, source}` 列表，只写可回读来源支持的原意，未发生的愿望照原意保留。
- `traits`：`{text, sourceRefs, limits}` 列表，简短有依据的理解，可以为空。
- `unknowns`：影响判断的未知内容，资料不足和冲突在这里说明。
- `read`：`{status, sources, note}`。status 为 success、unavailable 或 failed；sources 是实际读取/自动提供的来源引用。success 且 facts 为空表示成功读取但没有适合采用的线索。

检查点：来源实际存在且这次读过；原意与时长未被扩大；选择没有被当成长期人格结论；敏感原文和识别隐私的细节没有进入结果；读取失败与没有新事实分开。下游引用 facts 的 ID，已有了解可在有新来源时修订。
