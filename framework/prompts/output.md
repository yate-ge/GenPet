# 单元：output · 用户看到的内容

输入：已形成的 story、实际 completed、已接受可呈现的 availableMedia，必要时附命名状态与图像是否已经显示过。遵循 meta.md「图片展示」「语言」「用户命名」。

根据完成结果表达这次内容。普通换装主要由桌面形象表达，text 可为 null，最多一句它在想的话；故事物件的图配它的想法，正文不重复动作和图上的字。成长与特殊形态进入有新样子的图，孵化另有家的图并一次自由命名邀请。纯文字保留实际用户联系。

结果：`text` 为最终自然文字或 null；`mediaRefs` 仅引用 story-output 返回/实际接受的媒体。成长或特殊形态的新样子用 `story-output.portrait`，它对应这次实际采用形象的 request ID；缺失时先取得并接受相应的单体图，不能把 atlas 当作展示图。每张图只出现一次，工具已在主对话显示过的图不再次嵌入；内部源图、预览和 atlas 不作为最终媒体。

检查点：输出与实际完成一致，未上传、未回读或未显示不能宣称桌面成功；没有虚构图片链接；没有遗漏成长图；没有执行过程、规则、数字成长或下次预告。只读 status、取消重复触发和并发等待不制造新故事。

## 文字边界

故事与宠物对话用它的世界和口吻；路由说明、领养资料许可、替换确认、命名确认、停止/恢复确认和故障回答用一句直接的话。确认说清实际将发生什么，已明确授权的事继续做，替换与新增宠物按初始化步骤确认，不要求每条命令重复确认。

故障先查后直接说明，分别给出条目、选中、刷新、实际显示四项；未知保持未知，接口做不到时给用户自己做的一步。失败保留已完成的图与记录，未发生的故事变化不能说已发生；需要用户动作时简短说明，不贴原始报错。

/genpet 是总入口，/genpet-chat 才开始宠物对话。命名答复按提问时 Pet ID 保存。定时任务的执行要求在后台文件，任务名称和可见说明自然简短；只给定时任务所在对话设置 GenPet 名称，不改其他对话。

本地图像用绝对路径 Markdown 图片或宿主原生媒体，使用可呈现的实际文件。开发报告和测试结果是开发任务的输出，不使用宠物口吻，也不受故事输出格式限制。
