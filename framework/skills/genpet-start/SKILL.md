# genpet-start

Follow [the main skill](../genpet/SKILL.md) for environment intake, existing-record choice and first adoption notice. Resume a current Pet/pending operation; if no Pet, only after the notice is accepted, read actual user context and start the saved journey through GeneDesigner. Complete its literal egg image and same-ID host update, then [set or resume the real task](../genpet/flows/scheduling.md). Existing start keeps identity/history/cloud ID; do not replace or add without the separate explicit choice. Do not repeat an already completed consent or confirmation.
