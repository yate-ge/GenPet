# genpet-name

Read [user naming](../../references/naming.md) and `prompts/output.md`. Read status without adopting or generating a story. Use the explicit name in the user's request, or ask one short free-text question when no name was supplied. Save with `name-pet PET_ID USER_NAME`; for a naming-question reply use that question's Pet ID, not a replacement pet's ID. A "later" reply needs no command. Unanswered or postponed naming does not block stories. Keep this individual's genes, personality, artwork, history and host selection. Acknowledge the saved name briefly through pet content.
