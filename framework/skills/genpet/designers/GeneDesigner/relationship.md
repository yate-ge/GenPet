# 关系与旅程的创作参考

本文件供 GeneDesigner 需要时读。以下是设计参考，不能证明虚拟宠物必然形成亲密关系，也不用于诊断用户人格。

人与人关系研究把「感觉对方理解、重视并回应自己」作为形成亲近的一条路径。迁移到 GenPet 的判断是：让一条真实、非敏感的细节影响宠物的行动，比笼统说它懂用户更有依据。来源：[Reis、Clark、Holmes，2004，作者公开原文](https://www.sas.rochester.edu/psy/people/faculty/reis_harry/assets/pdf/ReisClarkHolmes_2004.pdf)。

四项研究发现分享积极事件与积极、建设性回应和关系体验有关。这给 GenPet 的参考是可以回应用户愿意分享的普通进展、选择和小成果，同时按宠物自己的性格表达；不要为了制造回应而推断情绪或评价生活。来源：[Gable 等，2004，论文原文](https://www.sas.rochester.edu/psy/people/faculty/reis_harry/assets/pdf/GableReisImpettAsher_2004.pdf)。

《宝可梦不可思议迷宫 救助队 DX》的官方说明显示开场问答影响角色，也允许玩家自行选择。可参考「用户的真实选择影响一个生命」这一形式；GenPet 用故事里的去处、线索和代价形成选择，不复制人格分数和固定角色表。来源：[官方游戏说明](https://www.pokemon.com/us/pokemon-video-games/pokemon-mystery-dungeon-rescue-team-dx/)。

《创世纪 IV》的原版手册把开场相遇与起始身份联系起来，保存后可以从原处继续。可参考把选择置于世界中的经历，并让后果延续。这里不据此判断用户道德，也不复用它的职业或德目体系。来源：[Sega 原版手册的公开转录](https://www.smspower.org/seganotebook/ultima4/manual/ultima4m.html)。

创作时选择相似或互补的关系，简要说明它怎样形成有趣而舒适的相处：双方共同留意什么，它会用自己的方式怎样回应，又有什么自己的倾向。一次选择只支持当时的理解，后来相处由 memory 更新。把来源、具体设计理由和限制保存在 genes/personality 的结果里，不在领养总结展开研究或人格分析。
