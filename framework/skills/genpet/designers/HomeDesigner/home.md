# 单元：home · 它的家（HomeDesigner）

输入：context、pet.state.home、已形成的 story 与 homeIntent、savedArt。遵循 ../../rules.md「故事物件与家」「语言」。

孵化时建立家，之后按故事添置、整理、存放、取出、移走或搬家。说明现在能生活的布局，延续已有物件与位置；存放旧物可以简要合并，完整历史和素材仍保存。尚未孵化时没有家。

结果：`home` 是变化后的完整家描述，含位置、周围、按它的习惯形成的分区、当前摆放和与旧家的联系；无变化为 null。`visual` 为 `{purpose, form, mustShow, request, references}` 或 null。孵化和搬家有全景；其他由变化是否值得看决定。图以家为主体，宠物只是其中一部分，画幅按布局决定。

图中出现宠物时，把本只本阶段实际接受的单体图作为身份和像素风格参照，旧家图只负责布局与物件连续性。宠物保留原有色块、轮廓与器官，用简洁的像素构造进入家景；家的环境与它协调，不把宠物画成平滑插画后只给边缘加锯齿。

检查点：整体与周围看得清，能活动而非角落特写；物件来源和去向有故事依据，没有隐私事实；描述与真实图一致；搬家是新地方的完整设计；变化和久别的时间产生联系而不猜用户原因。
