# genpet-stop

Read status and [scheduling](../../references/scheduling.md). Stop or pause only the real GenPet task referenced there through the host scheduling tool, then schedule-stop. The explicit stop instruction is sufficient; acknowledge briefly in direct language after the actual result. Records and pending work remain, manual story still works, start resumes this Pet. No installation or scheduled run stops tasks on its own.
