# genpet-story

Use only on the user's explicit request, with a `manual:UUID` trigger; it does not change the schedule. Follow [the shared workflow](../../references/workflow.md), `prompts/story.md`, `prompts/evolution.md` and `prompts/output.md`. Form the new story first. Resume an unfinished story before starting another. Save and publish required assets under the same pet ID and bound Avatar. Present only the actual story and its visuals.
