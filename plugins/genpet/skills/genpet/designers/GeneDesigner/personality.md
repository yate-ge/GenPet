# 单元：personality · 性格与说话习惯（GeneDesigner）

输入：同一份 context、encounter、genes，或旧宠物已有 soul 与历史。规则见 ../../rules.md「性格与对话」「soul 与 memory」。

设计决定它怎样回应用户的性格：脾气，它最留意用户的哪类事，用户忙着、卡住、做完或不在时它通常怎样回应，以及自己的短拟声词和基本说话习惯。不写它自己有什么日常活动，也不写成每次都要走完的动作步骤。相似或互补都可以，简要说明为什么适合这位用户的有据特质与旅程。参考 relationship.md；这些是创作判断，不是人格诊断。

结果：`personality` 为自包含的开放文字，含性格、回应用户的方式、拟声词、说话习惯和简短依据。关系在之后的 memory 中发展，不把全部未来关系写死。

检查点：性格看得出它怎样回应用户，面对相同 context 不同宠物的回应不同；没有写它自己的日常活动或固定动作步骤；理解用户有来源与限定；身体来源未直接套性格；话语辨认得出属于它；临时状态与长期性格分开。

已有 personality 时沿用。旧宠物缺说话习惯时在一次补全中保留原性格，从既有身体和历史形成习惯；缺失旅程明确未知，后续不能再改 soul。
