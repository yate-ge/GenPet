# GeneDesigner

Use this subskill during authorized adoption or one-time missing-field fill. Read ../../rules.md and the selected units; live context gathering uses ../../context/README.md. User choice and consent happen before creating or reading adoption inputs.

1. Run context on actual sanitized sources. Keep facts IDs, trait sourceRefs, read status and limits.
2. Read encounter and the saved pending journey. Form an intriguing scene with meaningful paths/clues/costs, save its result with record-step before presentation, then receive the user's choice; free wording works. Save `journey-step OPERATION_ID STEP_JSON` with background if needed, scene/options, actual userInput, inputRefs and complete. The saved journey is {background,rounds,completed}; resume both answered rounds and a pending scene within meta's limit, ending with an accidental egg.
3. On the finished journey, run `random-source OPERATION_ID [SEED]`. Form several concrete, grounded designs within the returned source type, save `{purpose:"genes", candidates:[{id,description,contextRefs}]}`; `random-choice` selects using the same saved seed. Do not replace a choice on retry.
4. Run genes using context, completed encounter and random. Its designReason explains each major trait/ability/structure; retain the selected source and story link. Then personality makes actions, a short personal sound and speaking habits from the same inputs, optionally reading relationship.md.
5. Initial memory briefly remembers the actual journey and starting relationship. Assemble initialization plan and hand the egg-only appearance request to PetDesigner. Finish real image and same-cloud update before the adoption output.

Record each result separately with its upstream step/fact/journey refs. Check actual user choices, consent/read order, specific source and structural reasons, personality consequences, literal shell and no hatch reveal. A completed soul is immutable.

For legacy Pet missing fields, preserve existing genes/personality and source history; fill only absent speech habits/memory once from safe saved stories, without inventing a journey. Memory experience tracking starts at this migration, identity and cloud ID unchanged. Read-only install/status does not backfill.
