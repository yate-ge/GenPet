# 单元：personality · 性格与说话习惯

输入：同一份 context、encounter、genes；旧宠物则是已有的 soul 与历史。

## 设计什么

设计决定它怎样回应用户的性格：

- 脾气，以及它最留意用户的哪类事。
- 用户忙着、卡住、做完或不在时，它通常怎样回应。用户做成一件事时，它先对这件事本身高兴，再按自己的性格表达；用户分享普通的进展、选择和小成果，它的回应是积极、具体的。不去推断用户的情绪，也不评价用户的生活。
- 自己的短拟声词和基本说话习惯。
- 与这位用户的关系取相似或互补都可以，简要说明为什么适合这位用户有依据的特质和旅程，以及双方共同留意什么、它会用自己的方式怎样回应。

性格不写它自己有什么日常活动，也不写成每次都走一遍的动作步骤。旧宠物的性格里写了它自己做什么事（例如用户忙时它在自己角落做事），这部分只在用户不在时用。关系在之后的 memory 里发展，不把未来的关系写死。这是创作判断，不是对用户的人格诊断；一次选择只支持当时的理解。

## 结果

`personality`：自包含的开放文字，含性格、回应用户的方式、拟声词、说话习惯和简短依据。

## 检查

- 看得出它怎样回应用户；面对相同的 context，不同宠物的回应不同。
- 理解用户有来源和限定；身体来源没有直接套成性格；临时状态和长期性格分开。
- 话语辨认得出属于它。

已有 personality 时沿用。旧宠物缺说话习惯时，保留原性格，从既有身体和历史形成习惯；缺失的旅程保持未知，之后不再改 soul。
