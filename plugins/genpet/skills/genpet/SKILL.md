# genpet

Read [the shared workflow](../../references/workflow.md) and `prompts/output.md`. The conversation contains only pet stories and actual story visuals, including intermediate messages. User context, evolution and content are Agent decisions; genes and identity persist. Start/resume through /genpet-start, new stories through /genpet-story. Explicit pet dialogue is allowed only when the user requests it through a command. Product discussion or installation does not adopt, reset or generate a pet.
