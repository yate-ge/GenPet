# genpet-switch

Run `switch-pet --list`, `switch-pet --current` or `switch-pet ACTUAL_PET_ID` from this installed plugin runtime as requested. Switching selection is separate from updating the bound GenPet target. Do not guess IDs from names or reset records. This command is desktop-only. Follow `prompts/output.md` for conversation content.
