# GenPet

A story-driven pixel Pet for Codex. The installed version is in `.codex-plugin/plugin.json`; changes are listed in the repository's [CHANGELOG](https://github.com/yate-ge/GenPet/blob/main/CHANGELOG.md).

Each Pet starts as a literal egg designed from its adoption story and hatches into a cute living companion. Product principles are in [skills/genpet/principles.md](skills/genpet/principles.md).

Use `/genpet` for everything about the Pet: adopting or resuming, status, naming, pausing the scheduled checks, replacing it or adopting another, switching the desktop Pet and diagnosis. Use `/genpet-chat` to talk, and `/genpet-debug` to open the record page, request a story or force a growth step. Adoption begins with a data notice and consent, then a journey of up to five choices. Scheduled checks run every five hours while the host is available. A completed hatch invites naming once.

The shared runtime supports desktop and cloud main environments. v3 records have soul, memory and state, one directory per Pet and one active Pet. Accepted artwork and the brief target the same cloud Pet ID; stored-image verification, refresh and actual display are separate results. See [adoption](skills/genpet/adoption.md), [stories and scheduling](skills/genpet/stories.md), [artwork](skills/genpet/art.md) and [host, Dots and records](skills/genpet/host.md). Installing alone creates no Pet or task.
