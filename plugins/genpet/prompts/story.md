# 单元：story · 它的新经历（StoryDesigner）

输入：context、同一只宠物的 pet（soul、memory、state）、growth、recentContent（实际最近内容、类型间隔、未完事项）、random（已有候选和种子选择）；可附 time、用户请求与保存素材。规则见 meta.md「故事与换装」「故事节奏」「用户联系」「时间感」。

先形成差别明显、各有依据的故事候选，其中至少一个有可见结果，然后采用随机工具选定的候选，写出它的经历。重试用同一份候选与选中结果。类型来自故事结果，不先按类型分配剧情。

用它的性格、memory、家和已有物件，让这次 context 进入它自己的目的或想法。平常可只为一次换装形成简短经历；有真实用户节点或成长时更完整。growth.required 不为空时承载必须发生的变化；成长时回顾 memory，不补造用户节点。

结果：

- `text`：故事草案，内部可以写清行动；最终可见文字交 output。
- `connection`、`factIds`：用户联系及其实际事实 ID；不足如实记。
- `stateIntent`：故事后的状态意图，含看得见的换装或保持原样。
- `visualIntent`：用户该看到什么、它要表达什么；纯文字写清对应用户 context。
- `homeIntent`：家的变化意图，无变化或未孵化为 null。
- `memoryIntent`：确有值得记住的事时写完整、简短的重写意图，否则 null。

检查点：每次有内容；所选内容来自实际候选，纯文字有真实用户线索且未超过连续上限；宠物像被养着的同伴；性格与相处改变回应方式；正在做的事推进而非每次重开；前后物件和日期一致；长久空档有联系且不猜原因；memory 值得记而非逐次流水账；没有提问、邀请或下次预告。
