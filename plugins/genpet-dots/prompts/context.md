# 单元：context · 关联依据

输入：`availableContext` 是本次实际可用的资料；可以附加用户请求、宠物记录和任务目的。正常调用由 Agent 自行选择资料来源与范围。单元测试只使用提供的输入，不额外读取真实用户资料。

步骤：

1. 选择与当次相遇或新故事有关的真实线索。
2. 为每条线索写稳定引用、事实摘要与来源；推测和宠物世界的虚构情节不能作为用户事实。
3. 将会影响后续判断、但目前未知的内容记入 unknowns。资料稀少时保留有限联系，不补齐人物设定。

结果：`facts` 为 `{id, text, source}` 的列表；`unknowns` 为未知内容的文字列表。只保存相关摘要，不复制全部资料。没有相关事实时 facts 可以为空。

检查点：事实能否回到输入中的来源；是否编造用户工作、偏好或情绪；是否把资料不足藏在后续通用故事中。

后续单元直接引用这些事实 ID，不重新抽取一套互相矛盾的用户设定。结果留在内部。
