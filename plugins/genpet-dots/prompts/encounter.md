# 单元：encounter · 相遇与地点

输入：context 的结果；可附加本次探险语境和用户请求。资料范围不由本单元另行扩展。

步骤：

1. 从事实或明确的相遇意愿中建立有意义的联系。
2. 形成宠物世界中的获得经历与具体地点，让该地点在经历中有来由。
3. 核对每个涉及用户实际情况的叙述，引用事实 ID；宠物的探险与生活可以虚构。

结果：`text` 为获得蛋的故事草案；`place` 为地点；`connection` 说明这次相遇为何与用户有关；`evidenceIds` 引用 context 中实际采用的事实 ID。资料不足时 connection 如实说明有限联系。

检查点：联系是否来自具体事实而非替换名字、职业或兴趣；地点是否由相遇经历形成；是否把宠物探险写成用户真实旅行。保留故事中可供 genes 单元选择灵感的具体线索；身体设计留给 genes 单元。
